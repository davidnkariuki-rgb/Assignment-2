Uniform Resource Locators (URLs)

A URL is the address used to locate resources on the Web. It specifies the protocol, domain, and path needed to retrieve a web page, image, or file.

URL parts

  • Protocol: http:// or https://
  • Domain: example.com
  • Path: /page/name
  • Query string: ?key=value
