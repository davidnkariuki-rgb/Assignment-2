Web Browsers

A web browser is an application used to retrieve, render, and display web pages. Browsers translate HTML, CSS, and JavaScript into the visual pages users interact with on the Web.

Common browsers

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

How it works

The browser sends an HTTP request to a web server, receives HTML, parses the document, applies styles, runs scripts, and displays the final page.
