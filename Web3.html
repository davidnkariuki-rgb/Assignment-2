Web 3.0

Web 3.0 is the emerging Web built around decentralization, blockchain technologies, semantic data, and user-owned identity.

Common ideas

  • Decentralized applications (dApps).
  • Blockchain and smart contracts.
  • Improved data privacy and user control.
