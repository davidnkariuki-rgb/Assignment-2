File Transfer Protocol (FTP)

FTP is a standard network protocol used to transfer files between a client and server over a TCP/IP network.

FTP features

  • Supports file upload and download.
  • Can use secure variants such as FTPS or SFTP.
  • Requires a client application or browser with FTP support.
